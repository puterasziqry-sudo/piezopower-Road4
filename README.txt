PIEZOPOWER ROAD — GITHUB PAGES
1. Upload all files and the assets folder to your GitHub repository.
2. Make sure index.html is in the repository root.
3. GitHub → Settings → Pages → Deploy from branch → main → /(root).
4. Save and open the generated Pages URL.

The website is already split into separate HTML pages.
All team photos and the prototype image are stored locally in assets/.
Road/banner photos are loaded from Wikimedia Commons.

Updates: each page now uses a different Malaysian road banner; Home includes SDG 7 content with the supplied image and a YouTube explainer video.
